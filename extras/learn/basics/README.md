# Python basics (no swayforge, no TUI)

Plain Python, nothing to install. Five short lessons in the files `lesson01.py` … `lesson05.py`.

1. `cd extras/learn/basics`
2. `python3 lesson01.py`  – run it, read what it prints
3. open the file (`nano lesson01.py`), read the comments, do the TASKS at the bottom (replace each `...`)
4. run it again – lines saying `OK` mean you got it, `NOPE` tells you what was expected

Stuck? Send me the lesson number and what you tried. Hint or full solution – you choose.
